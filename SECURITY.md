# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability

We take the security of Plynk and our users' data seriously. As an offline-first desktop workspace with zero telemetry and local SQLite persistence, safeguarding local data integrity and system isolation is our top priority.

### Disclosure Process

If you discover a potential security vulnerability in Plynk:

1. **Do not create a public issue** on GitHub.
2. Please report the issue privately via [GitHub Security Advisories](https://github.com/TrisH0x2A/plynk/security/advisories/new).
3. Include detailed steps to reproduce the vulnerability, along with your operating system, desktop environment, and Plynk version.

### Response Timeline

- **Initial Response**: Within 48 hours to acknowledge receipt of your report.
- **Assessment**: Within 5 business days with an assessment and estimated timeline for a patch.
- **Fix & Disclosure**: A security patch will be released, after which a coordinated public disclosure will be made.
